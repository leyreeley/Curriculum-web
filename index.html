Proyectos y Trabajos

Aplicación de Gestión de La Liga de Fútbol

Descripción: Desarrollo colaborativo de una aplicación de escritorio completa para la gestión integral de la Primera División de Fútbol. Proyecto final de primer curso desarrollado en un equipo de tres personas.

Herramientas: Java, MySQL, FlatLaf (UI), GitHub (Control de versiones en equipo), NetBeans.

Proceso: Diseño del modelo relacional, inserción de datos reales, programación de la lógica en Java y reparto de tareas mediante repositorios.

Resultado: Una aplicación robusta con menús navegables para gestionar de forma persistente equipos, jugadores y sus estadísticas.

Dificultades: Coordinar las fusiones de código entre los tres compañeros y gestionar la vinculación de las claves foráneas en la base de datos.

Aprendizaje: Importancia de la comunicación técnica, el uso de Git en entornos colaborativos y la estructuración del código.
